# Azeroth Survivors Save Editor

Статический редактор сохранений оригинальной Azeroth Survivors. Открывает `.sav` и строки `RSE1:`, позволяет менять зоны, таланты, кодекс, достижения, предметы, экипировку, статистику и сырой текст. Экспортирует подписанный `.sav` или строку RSE1. Каталог содержит 354 ID талантов из текущего `.exe`; неизвестные ID можно ввести вручную. Все вычисления выполняются в браузере; файлы никуда не отправляются.

## Запуск

```powershell
python -m http.server 8000
```

Откройте `http://localhost:8000/`. Прямое открытие `index.html` через `file://` не подходит: браузер блокирует загрузку `data/catalog.json`.

## Публикация на GitHub Pages

1. Отправьте изменения в ветку `main` репозитория [darhanger/AzerothSurvivors-SaveEditor](https://github.com/darhanger/AzerothSurvivors-SaveEditor). Файлы `.sav` исключены через `.gitignore`.
2. В настройках репозитория выберите **Pages → Build and deployment → Source: GitHub Actions**.
3. Workflow [pages.yml](.github/workflows/pages.yml) публикует только `index.html`, `styles.css`, `src/` и `data/`. Адрес появится в завершённом запуске Actions.

Редактор рассчитан на экспорт RSE1 из исследованного Windows-билда. Формат и каталог могут измениться в новых версиях игры. Перед импортом в игру сохраните исходный сейв: импорт заменяет весь аккаунт.

## Новый амулет друида

На скриншоте игры недостающий амулет связан с `Shred` (`140 / 141` записей кодекса). В текущем бинарнике есть способность `shred`, а в предоставленном сохранении нет `legendary:shred`. Редактор показывает её в разделе **Кодекс → Легендарные амулеты** и добавляет запись `legendary:shred=4` одной кнопкой. Факт отображения после импорта нужно проверить в игре.

Технический разбор формата: [docs/format.md](docs/format.md).
