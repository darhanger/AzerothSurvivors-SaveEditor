# Azeroth Survivors Save Editor

Редактор сохранений **Azeroth Survivors** в браузере. Откройте экспортированный файл `.sav` или вставьте строку `RSE1:`, измените прогресс и экспортируйте новый файл или строку для игры. Обработка выполняется в браузере; у сайта нет сервера для загрузки файлов.

**[Открыть редактор](https://darhanger.github.io/AzerothSurvivors-SaveEditor/)**

## Возможности

- Импорт сохранений RSE1 с проверкой подписи и редактирование открытого текста сейва.
- Управление открытыми и пройденными зонами, опытом и рангами талантов, кодексом украшений, достижениями, коллекцией предметов, экипировкой, статистикой, перками и спутниками.
- Открытие легендарного амулета друида **Shred**. Запись `legendary:shred=4` уже проверена в игре после импорта.
- Фильтр экипировки по классу и режим просмотра всех классов. Новые доступные PvP-комплекты показаны неотмеченными.
- Отдельные иконки предметов по классу, комплекту и ячейке, а также записи кодекса. У легендарных амулетов показана иконка связанного заклинания со значком амулета.
- Счётчик полученных, потраченных и свободных очков талантов и шкала опыта до следующего очка.
- Переключение между английским (по умолчанию) и русским. Выбор хранится локально в браузере.
- Экспорт заново подписанного файла `.sav` или строки RSE1. При изменении через формы неизвестные строки сейва сохраняются.

## Как пользоваться

1. Откройте [редактор](https://darhanger.github.io/AzerothSurvivors-SaveEditor/).
2. Перетащите `.sav` или `.txt` на страницу, выберите файл либо вставьте строку `RSE1:`.
3. Измените нужный раздел. Вкладка **Открытый текст** даёт прямой доступ ко всем строкам сейва.
4. Скачайте изменённый `.sav` или скопируйте строку RSE1, затем импортируйте её в игру.

**Сохраните копию исходного сейва.** Импорт в игре заменяет весь текущий прогресс аккаунта. Редактор не меняет исходный файл на вашем устройстве.

## Данные и ограничения

| Область | Источник | Примечание |
| --- | --- | --- |
| Контейнер RSE1 | Исследованный Windows-бинарник | Проверка подписи и экспорт используют формат текущей версии игры. |
| Классы и зоны | Данные игры и проверенные ID | Названия доступны на английском и русском. |
| Таланты | 354 ID и формула опыта из исполняемого файла | Первое очко стоит 80 опыта, каждое следующее на 15 больше; максимум 51. Правила рангов и веток проверяет игра. |
| Кодекс | Предоставленный сейв и данные игры | 141 запись, включая подтверждённый амулет Shred. Значения 0–4 задают сохранённое качество; «Скрыт» удаляет запись. |
| Собранная экипировка | Предоставленный сейв, названия комплектов игры и индекс иконок WoW | Подписи описывают класс, комплект и ячейку; это не полные игровые названия предметов. |
| PvP-экипировка | ID выведены из существующей схемы ID | Показана доступной и неотмеченной. Прежде чем массово менять комплект, проверьте один предмет в игре. |

Редактор рассчитан на **оригинальную отдельную Windows-игру Azeroth Survivors**, исследованную 18 октября 2026 года. Это не аддон World of Warcraft. Новая версия игры может изменить поля сейва, подпись или допустимые ID предметов. Технические детали: [разбор формата](docs/format.md).

## Локальный запуск

Из корня репозитория:

```powershell
python -m http.server 8000
```

Откройте `http://localhost:8000/`. При открытии `index.html` через `file://` браузер может заблокировать загрузку `data/catalog.json`. Сборка не требуется.

## Публикация

[Workflow GitHub Pages](.github/workflows/pages.yml) публикует `index.html`, `styles.css`, `src/`, `data/` и `assets/` после отправки изменений в `main`. Источник Pages в настройках репозитория — **GitHub Actions**. Файлы сохранений исключены через `.gitignore` и не попадают на сайт.

23 PNG-иконки классов и категорий в `assets/icons/` извлечены из локального `patch.MPQ`. В `assets/icons/game/` лежат иконки предметов и кодекса. Скрипт `tools/build_visuals.py` читает названия иконок кодекса и комплектов из `.exe`, сопоставляет броню с [зафиксированной версией индекса предметов WoW Classic](https://github.com/nexus-devs/wow-classic-items/tree/8339771805564c6de7850ff9428be8e841f69622) и сохраняет PNG из MPQ или, если файла там нет, из CDN иконок WoW. Для стартовых и PvP-комплектов используются характерные иконки: сейв не содержит точного варианта внешнего вида. Для нескольких заклинаний применены стандартные WoW-иконки, потому что в бинарнике путь отсутствует. Это влияет только на отображение, не на данные сейва. Для повторного извлечения установите `mpyq` и `Pillow`, затем выполните `python tools/extract_icons.py C:/WoW/Surv/Data` и `python tools/build_visuals.py C:/WoW/Surv`. Сайт загружает один атлас `assets/icons/game-atlas.png` из репозитория и не обращается к сторонним серверам за иконками.
